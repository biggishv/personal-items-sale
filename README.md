# Свои вещи

Одностраничный адаптивный лендинг для продажи личных вещей. React, TypeScript, Vite и Tailwind CSS. Каталог работает без сервера и базы данных.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Готовые статические файлы появятся в `dist/`.

## Настройка

- Контакт Telegram: `src/config.ts` — ник без `@`.
- Вещи, цены и описания: `src/data/items.ts`.
- Фотографии: `public/images/`.
- Цвета, типографика и адаптивная раскладка: `src/index.css`.

В текущей версии используются демонстрационные объявления. Перед реальными продажами замените их своими вещами и контактами.

## GitHub Pages

В проекте есть workflow `.github/workflows/deploy.yml`. После публикации репозитория включите **Settings → Pages → Source → GitHub Actions**. Сайт будет автоматически пересобираться при каждом push в ветку `main`.
